یہ ریپوزٹری سلسلہ عالیہ صوفیہ نوربخشیہ کی تمام اہم، مستند اور نایاب کتب، رسائل، اوراد اور فتاویٰ کا جامع ڈیجیٹل مجموعہ (Digital Library) ہے۔

This repository serves as a comprehensive digital library containing authentic books, treatises, litanies, and jurisprudential texts of the **Sufia Noorbakshia** spiritual tradition.

---

## 📖 تعارف | Overview

سوفیہ نوربخشیہ اسلامی تصوف، فقہ، اور علومِ اہل بیتؑ کا ایک معتبر اور تاریخی سلسلہ ہے۔ اس ریپوزٹری کا بنیادی مقصد ان تمام مبارک کتب اور رسائل کو محفوظ کرنا اور دنیا بھر کے طلباء، محققین اور عقیدت مندوں کے لیے آسانی سے دستیاب بنانا ہے۔

In this repository, you will find original PDF resources covering:
- **فقہ و احکام (Jurisprudence & Islamic Law)**
- **عقائد و کلام (Creed & Theology)**
- **تصوف، اخلاق و سلوک (Sufism & Mysticism)**
- **اوراد، وظائف و ادعیہ (Litanies & Supplications)**
- **آثار و رسائل شاہ ہمدانؒ و سید محمد نوربخشؒ (Works of Great Sufi Masters)**

## 🚀 استعمال اور ڈاؤن لوڈ کا طریقہ | Usage & Download

### Repositories Clone کریں:
بڑی PDF فائلوں کے لیے اس ریپوزٹری میں **Git LFS** استعمال ہوا ہے۔ ریپوزٹری کلون کرنے کے لیے:

```bash
# Git LFS Install کریں (اگر پہلے سے انسٹال نہیں ہے)
git lfs install

# Repository Clone کریں
git clone https://github.com/codewithnisar/sufia-noorbakshia-books.git
cd sufia-noorbakshia-books

# Git LFS Files Pull کریں
git lfs pull
```

### 📥 Direct Download:
آپ GitHub کی ویب سائٹ سے کسی بھی PDF پر کلک کر کے **Download Raw File** کے ذریعے براہِ راست ڈاؤن لوڈ کر سکتے ہیں۔
